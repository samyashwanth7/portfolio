( 02 ) — Capstone project

ByzAgent-IDS
agentic trust for federated learning

Federated learning lets organizations train a shared intrusion-detection model without exposing raw network traffic — but it opens the door to Byzantine poisoning, where a compromised participant slips bad updates into the global model. Standard defenses like Krum and Trimmed-Mean use fixed mathematical thresholds on a single round, so they miss gradual, adaptive poisoning that ramps up slowly to stay under the radar — and when they do reject a client, they give zero explanation why.

ByzAgent replaces that blind threshold with an LLM agent sitting at the aggregation server. After every round it tracks five behavioral stats per client — update norm, cosine similarity to the global model, cosine similarity to peer mean, local loss, validation drop — across a rolling history, and reasons over the trend to decide: trust, downweight, or quarantine. Every decision comes with a plain-language explanation a SOC analyst can actually audit.

View repository

What's actually new

  • No prior work uses an LLM agent as a dynamic trust arbiter in FL aggregation — existing agentic security work targets pen-testing or SOC alert triage, not aggregation itself.
  • Detects "slow-drip" label-flipping attacks that defeat Krum and Trimmed-Mean, by reading historical trend degradation instead of one-shot distance math.
  • Generates natural-language justifications per decision — e.g. flagging a client whose peer-similarity dropped from 0.94 to 0.61 over three rounds.
